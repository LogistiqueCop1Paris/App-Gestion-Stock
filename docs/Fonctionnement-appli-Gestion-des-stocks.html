Rôles

3 rôles distincts

Lecture + distributions

VSC

Ne peut pas modifier les éléments déjà présents dans les stocks. Ne peut pas ajouter ou retirer des produits dans le stock. Peut simplement faire des débuts de distribs et les clôturer.

A un accès en lecture à l'historique.

Gestion des stocks

Respo Autres

Peut modifier les produits, en ajouter, en retirer. Peut créer et supprimer des catégories dans les stocks.

Iel peut annuler des actions via l'historique. Ne peut pas transférer d'un stock à un autre.

Administration

Respo Log

Peut tout faire, rôle d'admin. Peut faire des transferts entre stocks.

Dans l'onglet Utilisateurs peut modifier les NOMS, prénoms, mails et rôles. Peut également supprimer des comptes.

Pour commencer

Création d'un compte

Pour avoir accès à l'appli, vous devez vous créer un compte personnel en renseignant votre NOM, prénom et email. Aucune de ces infos ne sera utilisée en dehors de l'appli — elles ne sont pas transmises.

Si vous quittez l'asso, ou que pour n'importe quelle autre raison vous souhaitez que votre compte soit supprimé, merci de contacter un Respo Log.

Navigation

Stocks

Permet de visualiser les stocks. Dans chaque stock, on retrouve la liste des produits ajoutés.

Quand on ajoute un produit, on précise :

  • la catégorie — si la correspondante n'existe pas, on peut en créer une
  • le nom du produit — même principe que pour la catégorie
  • la quantité (nombre entier)
  • la source — même principe que pour la catégorie et le produit
  • la date de péremption (optionnel, mais préféré)
  • commentaire (optionnel)

Si un produit existe déjà, il sera dans la liste déroulante, mais il est aussi possible de le chercher directement dans le tableau.

✓ Action réversible

Lorsqu'on retire une quantité d'un produit et que celui-ci tombe à zéro, il est supprimé. Si un stock est supprimé, tout ce qu'il contient l'est aussi.

Navigation

Distribution

Lorsqu'une distribution débute, vous pouvez choisir les produits qui vont sortir du stock. Évidemment, vous ne pouvez pas sortir plus de quantité d'un produit qu'il n'y en a déjà dans ce stock.

À la fin de la distribution, vous remplissez la quantité de chaque produit restant. Mettez 0 s'il n'en reste plus.

Il est impossible de commencer une nouvelle distribution dans ce stock si la précédente n'a pas été clôturée. Vous pouvez ajouter un commentaire en sortie et en clôture de distrib.

⚠ Pour l'instant, action NON réversible
Navigation · Respo Log uniquement

Transferts

Vous pouvez faire des transferts entre les différents stocks. Quand vous cliquez sur le bouton, vous pouvez choisir la quantité de chaque produit présente dans le stock de départ. Laissez vide si un produit n'est pas transféré.

⚠ Pour l'instant, action NON réversible
Navigation

Statistiques

Un suivi des stats de distribution a été intégré. On peut y voir les chiffres qui ont été faits chaque mois, par lieu et par année.

En cliquant sur un mois, il est possible d'avoir en bas le détail de ce mois-ci :

  • le nombre de distribs
  • le total de paniers
  • le nombre de paniers en moyenne (parce que pourquoi pas)
  • et le détail de chaque date de distrib
Opération technique

Vider l'historique

Si jamais vous souhaitez vider l'historique :

  1. Aller sur supabase.com, ouvrir le projet Gestion Stock Paris.
  2. Dans le SQL Editor, ouvrir un nouveau fichier, coller cette commande :
truncate table public.mouvements;
  1. Cliquer sur Run ou appuyer sur Ctrl + Entrée.
  2. Penser à fermer le fichier dans lequel la commande a été exécutée.
⚠ Cette action est irréversible.
